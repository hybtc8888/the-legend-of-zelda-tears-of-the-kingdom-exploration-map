# ゼルダの伝説 ティアーズ オブ ザ キングダム — ハイラル探索マップ

[English](../../README.md) · [简体中文](../zh-Hans/README.md) · **日本語** · [Español](../es/README.md) · [Русский](../ru/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md)

Appleシリコン搭載Macで、MacNativeGames版 **1.4.3** のゲーム内マップに探索ポイントを表示するModです。空・地上・地底の切り替え、スクロール、拡大縮小に連動します。解放済みの祠や破魔の根はゲーム本来のアイコンからワープできます。

- 基本パックは4,436地点。コログのミ800個分の単独ポイントと、2個ずつもらえる運搬100件を合わせ、**1,000個**を網羅。運搬データには出発地点と目的地を収録しています。
- 祠152か所、破魔の根120か所、鳥望台15か所、ゾナウギア製造機30か所に加え、洞窟、井戸、宝箱、防具、龍の泪、ボスなどを表示します。
- 進行状況に対応する収集地点は入手すると消えます。復活するボスやライネルは倒すと暗くなり、復活すると元に戻ります。フィルターをオフにすれば完了地点も確認できます。
- 初期状態では全10グループが有効で、表示設定はグループごとに保存されます。

## Macへの導入

Appleシリコン搭載Mac、Python 3.14、MacNativeGamesのソースコード、お持ちのゲーム本体と **1.4.3** 更新データを用意してください。Appのビルドは [MacNativeGamesの導入ガイド（英語）](https://github.com/ly05010419/MacNativeGames/blob/main/docs/install.md) を参照してください。

1. このリポジトリのルートで `python3.14 mac/integrate.py "/path/to/MacNativeGames"` を実行します。
2. そのソースから1.4.3のMac Appをビルドまたは更新します。更新時は先にゲームを終了してください。
3. 展開済みの1.4.3 RomFS（通常は `totk/extracted/v143/romfs`）を使い、`python3.14 build_map.py "/path/to/romfs" map-points.json` でマップパックを生成します。
4. `python3.14 mac/configure.py map-points.json --language ja` でインストールします。Enterですべて有効にするか、除外するカテゴリ番号を空白区切りで入力してください。`--all` で選択を省略できます。

言語はMacのメニューバーの **View → 探索マップ → 言語** で変更できます。`--language auto` はシステムの言語に従います。言語を変えてもカテゴリの選択は保持されます。マップパックは手元のゲームデータから作成し、進行状況はゲームから読み取るため、セーブデータの編集は不要です。

探索マップのパネル末尾にある **语言Language：…** からも切り替えられます。パックに翻訳が含まれている場合は、マーカーの詳細も選んだ言語で表示されます。

## 操作

ゲームのマップを **Tab / M** またはコントローラーの **−** で開きます。キーボードの **3 / 5** または十字キーの **↑ / ↓** で階層を切り替えます。

| キー | 操作 |
| --- | --- |
| **⌘⇧L** | カテゴリとショートカットのパネルを開閉 |
| **⌘⇧M** | 探索レイヤーの表示切替 |
| **⌘⇧P** | 進行状況フィルターの切替 |
| **⌘⌥1–9** | 対応グループの表示を切り替えて保存 |
| **⌘⌥0** | ミニゲームの表示を切り替え |

1. 地形・探索 · 2. 収集品・素材 · 3. 敵・ボス · 4. 宝箱 · 5. コログ · 6. 装備 · 7. チャレンジ · 8. 集落・施設

**R3** を短く押すとパネルを開閉し、約0.7秒長押しするとレイヤーを切り替えます。パネル内は十字キーの上下で選択、左右で改ページし、ゲームの決定・戻るボタンで操作します。矢印キー、Enter、Esc、マウス、ホイールにも対応します。
