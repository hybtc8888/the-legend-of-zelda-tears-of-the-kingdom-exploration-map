# 塞尔达传说：王国之泪 · 海拉鲁探索地图

[English](../../README.md) · **简体中文** · [日本語](../ja/README.md) · [Español](../es/README.md) · [Русский](../ru/README.md) · [Français](../fr/README.md) · [Deutsch](../de/README.md)

适用于 Apple 芯片 Mac 上 MacNativeGames《塞尔达传说：王国之泪》1.4.3 的游戏内探索地图。它为天空、地上和地底补充可开关的点位、实时收集进度和攻略提示。游戏已有图标优先使用原生显示。

## 功能

- **三层地图。** 点位跟随原版地图的层级、移动和缩放。神庙、树根、鸟望台、地名、洞穴、水井、深穴、五大神殿、大妖精之泉、村庄、驿站、龙之泪、残旧的地图和左纳乌制造机沿用游戏原生显示。原版地图处理选择和传送，探索图层为其余点位绘制图标。
- **基础包有 4,436 个点位。** 包含完整的 1,000 颗呀哈哈种子，分别对应 800 个单颗点位和 100 组双颗搬运任务。搬运任务的地图数据记录起点和目的地。
- **实时进度。** 支持进度追踪的呀哈哈、宝箱、防具等点位完成后变暗，可统一隐藏。可刷新的 Boss 和人马被击败后仍显示为暗色，刷新后恢复亮度。
- **十个分类开关。** 安装时默认全选，游戏内随时切换。宝箱、装备、呀哈哈、大妖精和小游戏各有独立开关。
- **19 个小游戏起点。** 有原生地名的沿用原版显示，其余场地标注报名位置。进行中的目标和比赛进度由游戏管理。
- **按需操作面板。** 键盘和手柄共用「探索地图」面板。需要时才显示分类、快捷键和操作说明。
- **七种语言。** 游戏内菜单、快捷键面板、分类名称和安装提示支持简体中文、英语、日语、西班牙语、俄语、法语和德语。
- **本地生成。** 点位从玩家自己的 1.4.3 RomFS 生成。探索进度从运行中的游戏读取，游戏存档无需改动。

| 分类 | 包含内容 |
| --- | --- |
| 地标 | 152 座神庙、120 个树根、15 座鸟望台，以及神殿、村庄、驿站、地名和天空群岛 |
| 洞穴与设施 | 洞穴入口、地洞入口、井、大妖精、30 台左纳乌制造机、旅馆、杂货店、防具店、染色店和珠宝店 |
| 收集 | 呀哈哈、搬运呀哈哈、宝箱、防具、贤者的遗志、残旧的地图、依盖队设计图、龙之泪、魔犹伊和卡邦达立牌 |
| 敌人 | 岩石巨人、独眼巨人、人马、古栗欧克、巨霸伽马、方块魔像和莫尔德拉吉克 |
| 小游戏 | 滑盾、一始和沃托里拉力赛、空岛跳水、骑马障碍赛、矿车射靶等 |

可选的点位导入会补充任务起点和部分采集位置。

## 游戏内操作

用默认键盘按键 **Tab** 或 **M** 打开地图，按 **3** 往天空切换，按 **5** 往地底切换。手柄用原版 **－** 打开地图，用十字键上下切换层级。

打开地图后按 **⌘⇧L** 或短按手柄 **R3**（按下右摇杆）展开面板。也可以从 Mac 菜单栏进入 **显示 → 探索地图**。

| 键盘快捷键 | 操作 |
| --- | --- |
| **⌘⇧M** | 开关整个探索图层 |
| **⌘⇧P** | 统一显示或隐藏已收集和已完成的点位 |
| **⌘⇧L** | 展开或收起分类与完整快捷键说明 |
| **⌘⌥1–9** | 开关对应分组，保存设置 |
| **⌘⌥0** | 开关小游戏 |

数字 1–9 依次是地标与探索、收集与素材、敌人与 Boss、宝箱、呀哈哈、装备、任务、村镇与设施、大妖精。

小游戏开关控制 MOD 增加的点位和提示框。游戏本身的地名和进行中目标继续由原版地图显示。

在探索地图面板最后一项选择 **语言Language：…** 即可切换。鼠标、键盘和手柄都可以操作，选择会立即保存。数据包含有译文时，标记详情也会随之切换。


| 手柄操作 | 效果 |
| --- | --- |
| 短按 **R3** | 展开或收起面板 |
| 长按 **R3** 约 0.7 秒 | 开关探索图层 |
| 面板内十字键 **↑ / ↓** | 选择一行 |
| 面板内十字键 **← / →** | 向前或向后翻页 |
| 面板内按游戏确认键 | 切换选中项 |
| 面板内按游戏返回键 | 收起面板 |

面板也支持鼠标点击和滚轮。键盘用方向键选择或翻页、回车确认、Esc 收起。收起面板后，地图选择和传送继续使用原版操作。

## 在 Mac 上安装

准备 Apple 芯片 Mac、Python 3.14、MacNativeGames 源码目录，以及自己的游戏本体和 **1.4.3** 更新。从源码构建和更新 App 的步骤见 [MacNativeGames 中文安装指南](https://github.com/ly05010419/MacNativeGames/blob/main/docs/install.zh-CN.md)。

1. 下载本项目，在项目目录运行以下命令，将探索图层接入 MacNativeGames。

   ```sh
   python3.14 mac/integrate.py "/path/to/MacNativeGames"
   ```

2. 从接入后的源码构建或更新 **1.4.3 Mac App**。已有 App 时，先退出游戏，并从接入后的 MacNativeGames 源码目录运行更新流程。
3. 用解包后的 1.4.3 RomFS 生成地图包。若用 MacNativeGames 的构建产物，RomFS 目录通常位于 `<工作目录>/totk/extracted/v143/romfs`，其中有 `index.json` 和 `romfs.bin`。旧地图包需要重新生成，才能加入小游戏点位。

   ```sh
   python3.14 build_map.py "/path/to/romfs" map-points.json
   ```

4. 安装地图包。按回车启用全部十组，或输入要取消的编号，用空格分隔。希望跳过选择时，可在命令末尾加 `--all`。

   ```sh
   python3.14 mac/configure.py map-points.json --language zh-Hans
   ```

   可用语言为 `en`、`zh-Hans`、`ja`、`es`、`ru`、`fr`、`de`。`--language auto` 跟随系统，省略参数则沿用已保存的语言。安装后可在 Mac 菜单栏 **显示 → 探索地图 → 语言** 即时切换，分类勾选随之保留。

5. 启动游戏，打开原版地图。看到点位后，按 **⌘⇧L** 或短按 **R3** 查看分类和按键。

## 点位详情

可从游民星空导入公开的地上、天空和地底点位及攻略文字，包括位置、注意事项和可得物品。缺少说明时，提示框仍显示名称、分类和坐标。鼠标悬停或将游戏地图准星移到标记附近即可查看。

生成基础包后，导入攻略文字并安装新的数据包。

```sh
python3.14 import_gamersky.py map-points.json map-points-detailed.json --romfs "/path/to/romfs"
python3.14 mac/configure.py map-points-detailed.json
```
